- 용도: 예선 제출용 데모 영상(YouTube 일부 공개)
- 길이: 4분 50초 목표, 5분을 넘기지 않음
- 화면: 로컬 웹 화면(`uv run legaldoctor web`) 녹화와 슬라이드 3장(문제, 평가표, Liner 활용)
- 내레이션: 구태언 본인 목소리. "말"은 읽는 원고, "화면"은 촬영 지시

- 화면 흐름: 2026.11.16 개편 화면 기준(28개 사인 첫 화면 → 튜토리얼 또는 검진 → 완료 창 → 검진결과표)
- Liner 표시: Liner가 일하는 순간마다 화면 아래에 자막을 띄움(예: "Liner Model · 계약서에서 위험 조항 추출", "Liner Search · 최근 판례·처분·법령 개정 검색"). 기다린 구간은 잘라 내고 같은 자리에 "실제 소요 ○초"를 띄움

## 0:00–0:30 문제

화면
- 슬라이드 1: 큰 글씨 "신생기업 10곳 중 6곳이 5년 안에 문을 닫는다"(5년 생존율 36.5%, 국가데이터처 2025년 기업생멸행정통계). 아래에 작은 글씨 세 줄
  - "변호사 첫 답까지 보통 1주 · 규제 검토 건당 100만~1,000만 원 · 상담 시간의 70%가 기초 조사"
  - "창업기업 5년 생존율 OECD 평균보다 11.6%p 낮음(28개국 중 26위)"
  - "공개 샌드박스 사례 2,859건 중 신속확인 사례 0건"

말
> 새로 생긴 기업 10곳 가운데 6곳이 5년 안에 문을 닫습니다. 폐업 사유에는 대개 자금 소진이라고 적힙니다.
> 하지만 자금 소진은 사망 시각일 뿐입니다. 그 앞에는 숨은 규제, 계약서 한 줄, 노무 분쟁 같은 법률 사인이 있습니다.
> 창업자는 무엇을 물어야 할지 몰라 변호사를 찾기도 전에 막힙니다.
> 변호사의 첫 답까지 보통 일주일, 규제 검토 한 건에 백만 원에서 천만 원이 듭니다. 그 상담 시간의 70%는 기초 조사에 쓰입니다.

### 1:35–2:05 검진항목 도출과 검진

화면

- 검진 아이콘 버튼 줄에서 "투자계약"이 선택된 것을 보여 줌 → "가상 예시 불러오기"(가상 신주인수계약 발췌)
- "검진항목 도출하기" → 위험도 순으로 나온 항목 목록(위험 높은 항목이 미리 선택됨) → "선택한 항목 검진"
- 진행 창: 진행률 막대와 아래 진행 기록이 쌓이는 모습. 대기 구간은 잘라 내고 "실제 소요 ○○초" 자막(녹화 때 잰 값)
- 진행 창이 그 자리에서 완료 창으로 바뀜: "투자계약 검진 완료 · 검진한 항목 ○개 · 위험 높음 ○개"

말
> 이번에는 운영 중인 회사의 투자계약서입니다. 리걸닥터가 위험한 조항을 원문 그대로 뽑아 위험도 순으로 보여 줍니다.
> 고른 항목을 법령 원문과 한 조문씩 대조합니다. 진행 상황은 이 창 하나에서 바로 보입니다.
> 변호사의 첫 답을 일주일 기다리던 기초 조사가 1분 안에 끝납니다.

### 2:05–2:45 검진결과표

화면

- 개인 책임 조항 판정 두 가지를 차례로 가리킴
  - "보호 규정 있음: 이 투자자 업권이 적용 대상인지 확인 필요(27장)": 근거 칸의 벤처투자법 조문
  - "보호 규정 못 찾음: 계약대로 개인에게 집행될 수 있음(27장)": 회생·해산 시 즉시 상환 조항
- 오른쪽 "변호사 권장조치" 칸을 가리킴
- 우상단 인쇄·PDF·DOC 아이콘 중 "DOC"를 눌러 파일이 받아지는 장면

말
> 대표 개인이 투자금을 갚게 되는 조항이 나옵니다. 지켜 줄 규정이 벤처투자법에 있지만 이 투자자에게 적용되는지는 따로 확인해야 합니다.
> 회생을 신청하면 바로 갚으라는 조항은 지켜 줄 규정을 찾지 못했습니다. 계약대로 대표 개인에게 집행될 수 있어 위험을 높게 둡니다.
> 항목마다 15년 현장에서 권해 온 변호사 권장조치를 붙였습니다.
> 결과표는 인쇄하거나 PDF, 워드 파일로 받아 변호사에게 들고 가면 됩니다.

## 2:45–3:15 리걸닥터 케어(2단계)

화면
- 2:45 검진결과표 위 "다음 단계 · 리걸닥터 케어" 띠 또는 완료 창의 "리걸닥터 케어 프로그램 고르기" → 셀프·상담·변호사 케어 3개 선택지 → "셀프 케어"
- 2:50 케어 화면 위 프로그램 패널: 셀프 케어만 켜지고 상담·변호사 케어는 "잠김". 아래 실행 보드(할 일 / 진행 중 / 완료 / 보류)와 검진 항목 "처음 → 지금"을 짚음
- 2:55 패널에서 "상담 케어로 바꾸기" → 첫 화면에 실행 상담 창이 바로 열림. 미리 해 둔 질문의 답변(근거 조문, 변호사 확인 필요 표시)과 보드 카드의 "상담 1"을 짚음
- 3:03 "변호사 케어로 바꾸기" → 변호사 검토 창이 열림. 변호사 확인 과제 목록, 과제별 "검토 요청", "전체 경과 보고서로 검토 요청"을 짚음. 보드 카드에 "변호사 검토 대상" 표시
- 3:10 왼쪽 항목의 "고친 자료로 재검진" 결과 "높음 → 낮음"과 위쪽 "위험 높음 N → N-1"

말
> 리걸닥터는 진단에서 멈추지 않습니다. 검진이 끝나면 권장조치를 실행 과제로 나눠 리걸닥터 케어로 이어 갑니다.
> 셀프 케어는 보드와 재검진으로 스스로 관리하고, 상담 케어는 과제마다 검진 근거 안에서 답합니다. 근거가 없으면 변호사 확인으로 넘깁니다.
> 변호사 케어를 고르면 변호사 확인이 필요한 과제가 따로 모이고 경과 보고서와 함께 변호사에게 바로 검토를 요청합니다. 고친 계약서는 다시 검진해 위험이 줄었는지 확인합니다.

## 3:15–3:45 규제팡

화면

> 배달로봇이 보도를 다니는 문제는 도로교통법이 막고 있고, 닮은 승인 사례들이 이 조문으로 특례를 받은 뒤에도 조문은 그대로입니다.
> 규정이 비어 있으면 신속확인 신청서 초안으로 정부에 묻고, 깊은 검토는 상담 준비서 한 장을 들고 변호사에게 갑니다.

- 녹화 전에 `python -m legaldoctor.web.warm_news`를 돌려 28개 사인 최신 동향을 미리 받아 둠(첫 조회 약 40초가 사라짐)
- 투자계약 검진, 리걸닥터 케어(셀프 케어로 시작, 실행 상담 1회, 재검진 1회. 녹화 전 다시 셀프 케어로 돌려 둠. 검토 요청 버튼이 보이도록 서버 `.env`에 `LD_CONTACT`를 넣어 둠)는 녹화 직전에 같은 세션으로 한 번 돌려 둠. 검진결과표의 "실제 판례·처분 사례" 표는 무관한 자료가 섞일 수 있어 비추지 않음. 대기 장면은 잘라 내고 "실제 소요" 자막을 넣음(녹화 때 잰 값)
- 투자계약 검진은 실행마다 개인 책임 조항 판정이 "보호 규정 있음/못 찾음"으로 갈릴 수 있음. 녹화 직전 결과를 보고 대본의 해당 문장을 맞춤

- 브라우저 확대 125%, 창 크기 1280×800 고정, 알림 끔. 다운로드 폴더 이름이 보이지 않게 함
- 터미널 장면에서 `.env`를 열지 않음. 키와 OC 값이 화면에 나오지 않게 함
- 영상 끝 자막: "가상 사례이며 법률 자문이 아님"
