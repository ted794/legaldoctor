- 화면: 웹 화면(`uv run legaldoctor web`) 녹화와 슬라이드 3장(문제, 평가표, 확장)

- 내레이션: 구태언 본인 목소리. "말"은 읽는 원고, "화면"은 촬영 지시
- 평가 수치: 2026.11.14. 실행 결과(`out/eval/report.md`). 녹화 직전에 최종 실행 값으로 바꿈

## 0:00–0:30 문제

화면
- 슬라이드 1: 위쪽에 "스타트업은 규제와 계약에서 죽는다". 아래에 숫자 두 개(공개 샌드박스 사례 2,859건 / 공개된 신속확인 사례 0건)와 한 줄("투자계약 한 줄: 투자대상기업 및/또는 이해관계인")

말
> 새 서비스를 만든 창업자는 "이거 해도 되나요?"에서 먼저 막힙니다. 규제는 법률 본문보다 시행령과 고시, 별표에 숨어 있습니다.
> 규제가 있는지 정부에 묻는 신속확인 제도가 있지만, 공개된 샌드박스 사례 2,859건 가운데 신속확인 사례는 한 건도 없습니다. 참고할 선례가 없습니다.
> 회사를 운영하면 계약서 한 줄이 창업자를 죽입니다. "회사 및/또는 이해관계인"이라는 말 하나로 대표가 투자금을 개인 돈으로 갚게 됩니다.

## 0:30–0:50 스타트업 리걸닥터

화면
- 1장 그림 전체. 왼쪽(범용 AI)과 오른쪽(리걸닥터)을 차례로 가리킴
- 오른쪽 입구의 "규제팡"과 "계약·노무 검진"을 가리킴

말
> 스타트업 리걸닥터는 스타트업이 죽는 28가지 사인을 죽기 전에 검진하는 사전상담 에이전트입니다.
> 규제가 사업을 막는 문제는 규제팡 메뉴가, 투자계약과 노무는 계약·노무 검진 메뉴가 맡습니다. 두 메뉴는 같은 원문 대조 엔진을 씁니다.

## 0:50–2:20 시연 1: 규제팡

### 0:50–1:20 입력

화면
- 웹 화면 첫 화면. 위쪽 메뉴에서 "규제팡"이 선택된 상태
- "그림으로 보여 주기"에서 미리 연습한 흐름도(편의점 → 배달로봇 → 각 동 현관, 앱 결제)를 그려 보냄
- "스무고개로 답하기"로 넘어가 질문 2개에 보기를 눌러 답함
  - "물건값과 배달비는 누가 누구에게 내나요?" → "고객이 우리 회사에 낸다"
  - "편의점은 우리 회사와 어떤 관계인가요?" → 보기 하나 선택

말
> 가상의 스타트업입니다. 아파트 단지 안 편의점 물건을 자율주행 로봇이 집 앞까지 배달합니다.
> 법률 용어를 몰라도 됩니다. 그림을 그려도 되고 사업소개서를 올려도 됩니다. 빈칸은 리걸닥터가 스무고개처럼 쉬운 질문으로 채웁니다.

### 1:20–1:30 사업 확인

화면
- 오른쪽 "리걸닥터가 이해한 사업" 카드에서 출처 칩(그림 1, 질문 2)을 가리킴
- "이대로 맞아요" 클릭

말
> 항목마다 어느 자료에서 읽었는지 출처가 붙습니다. 출처를 댈 수 없는 내용은 넣지 않습니다.

### 1:30–2:05 규제 지도

화면
- "규제 지도" 버튼 → 새 탭
- 판정 범례(명시 규제, 의제 리스크, 해석 리스크, 규정 공백)
- "보도 주행" 표에서 근거 조문 링크, 원문 인용, 위임 경로 한 줄(법률 → 시행령 → 별표)을 차례로 가리킴
- "현존 규제: 특례 이후 미개정"과 "같은 규정 특례 선례 N건" 표시를 가리킴

말
> 사업을 행위 단위로 나누고 행위마다 걸리는 규제를 네 가지로 판정합니다. 원문에 조문이 있는 명시 규제, 기존 업종으로 볼 여지가 있는 의제 리스크, 정부 해석이 막는 해석 리스크, 그리고 신속확인으로 물어볼 규정 공백입니다.
> 조문은 국가법령정보 원문에서 그대로 인용하고 법률에서 별표까지 위임을 따라 내려갑니다. 같은 규정으로 특례를 받은 사례가 있으면 붙이고, 그 뒤로 조문이 바뀌지 않았으면 지금도 남아 있는 규제라고 표시합니다.

### 2:05–2:20 신청서와 상담 준비서

화면
- "신속확인 신청서 초안"의 제출처·서식 링크와 "확인을 요청하는 사항"
- "변호사 상담 준비서" A4 한 장 전체

말
> 규정 공백은 신속확인 신청서 초안으로 바로 정부에 묻고, 깊은 검토는 상담 준비서 한 장을 들고 변호사에게 갑니다.

## 2:20–3:20 시연 2: 계약·노무 검진

### 2:20–3:05 투자계약 검진

화면
- 위쪽 메뉴에서 "계약·노무 검진" 클릭 → "투자계약 검진" 선택 → "가상 예시 불러오기"
- 불러온 가상 신주인수계약 발췌를 잠깐 스크롤(투자자: 가상신기술투자조합)
- "검진하기". 대기 장면은 잘라 내고 "실제 소요 N분" 자막
- 결과 목록에서 위험 높음 항목 세 개를 가리킴
  - "투자대상기업 및/또는 이해관계인에게 … 상환을 청구할 수 있다"
  - "이해관계인은 투자대상기업과 연대하여 상환금액을 지급한다"
  - "투자금의 2배에 해당하는 금액을 위약벌로"
- "검진표 열기" → 진단 사슬(13장 (가)~(라), Ⅱ란)과 "보호 규정 못 찾음: 계약대로 개인에게 집행될 수 있음(27장)" 판정, "변호사 심화자문 권함"을 가리킴

말
> 이번에는 투자계약서입니다. 리걸닥터가 조항을 원문 그대로 뽑아 법령과 대조합니다.
> 대표 개인이 상환을 떠안는 조항이 세 곳 나옵니다. 민법의 연대채무 조문은 이 조항을 뒷받침하지만, 창업자를 지켜 줄 규정은 찾지 못했습니다. 그래서 보호 공백으로 보고 위험을 높게 둡니다. 계약대로 개인에게 집행될 수 있기 때문입니다.
> 위험이 높은 항목은 검진표 한 장으로 정리해 변호사 심화자문으로 넘깁니다.

### 3:05–3:20 노무 검진

화면
- "노무 검진" 선택 → 미리 돌려 둔 결과 화면으로 전환
- 위험 높음 항목 두 개를 가리킴: 출근하고 슬랙으로 지시받는 프리랜서(근로자성), 지난달 급여 일부 미지급(체불)

말
> 노무도 같습니다. 매일 출근해 지시를 받는 프리랜서는 근로자로 볼 수 있고, 체불은 회사가 회생을 신청해도 대표 개인의 책임으로 따로 남습니다.

## 3:20–4:00 평가

화면
- 슬라이드 2: 요약표

| 항목 | 리걸닥터 | 범용 프롬프트 |
|---|---:|---:|
| 핵심 법령 적중(시행령·시행규칙 포함) | 80% | 70% |
| 조문 적중 | 45% | 33% |
| 허위 조문 | 0 | 0 |
| 트랙 일치 | 8/10 | 8/10 |

- 아래 작은 글씨: 사례 10건 이름, "범용 프롬프트 = 같은 Liner Model 단독"
- 의무기록 조회 사례 한 줄 강조: 범용 쪽은 의료법·개인정보 보호법만, 리걸닥터는 정보통신망법까지

말
> 공개 승인 사례 10건으로 확인했습니다. 승인 결과와 법령명은 입력에서 지웠고 같은 사례는 선례 검색에서 뺐습니다.
> 리걸닥터는 핵심 법령의 80%를 찾았고 조문 적중은 45%였습니다. 같은 모델에 그냥 물었을 때는 70%와 33%였습니다. 리걸닥터가 인용한 조문은 전부 원문으로 확인한 것이라 허위 조문이 나올 수 없습니다.

## 4:00–4:30 Liner API와 원문 대조

화면
- 1장 그림의 가운데 열(사실 확인 → 후보 생성 → 원문 대조 관문)을 확대
- "못 찾으면 탈락 · 허위 조문 0건" 표시를 가리킴

말
> Liner Model은 그림과 문서를 읽고, 스무고개 질문을 만들고, 계약 조항을 뽑고, 조문이 적용되는지 판정합니다. Liner Search는 규제 단서와 정부 해석을 찾아옵니다.
> 둘 다 후보만 냅니다. 확정은 국가법령정보 원문이 하고, 원문에서 근거 구절을 그대로 찾지 못하면 버립니다.

## 4:30–4:50 확장과 마무리

화면
- 슬라이드 3: 28가지 사인 표(구현: 규제팡, 계약·노무 / 로드맵: 개인정보·거래·지배구조·엑싯)와 아래 한 줄 "위험이 높으면 변호사 심화자문으로"

말
> 지금은 규제와 투자계약, 노무를 검진합니다. 같은 엔진으로 개인정보, 거래, 지배구조, 엑싯까지 넓혀 스타트업이 죽는 28가지 사인을 모두 검진하겠습니다.
> 창업자는 무료로 문제를 먼저 알고, 신속확인이나 변호사 상담으로 바로 넘어갑니다. 스타트업 리걸닥터였습니다.

## 촬영 준비

- 분석과 검진은 몇 분씩 걸림. 입력 장면만 실시간으로 찍고 결과는 같은 세션에서 미리 돌려 둔 화면을 씀. 대기 장면은 잘라 내고 "실제 소요 N분" 자막을 넣음
- 녹화 직전에 투자계약·노무 검진을 다시 돌려 짧아진 검진표 형식으로 화면을 확보함
- 그림 탭 흐름도는 10초 안에 그리도록 미리 연습함
- 브라우저 확대 125%, 창 크기 1280×800 고정, 알림 끔
- 터미널 장면에서 `.env`를 열지 않음. 키와 OC 값이 화면에 나오지 않게 함
- 영상 끝 자막: "가상 사례이며 법률 자문이 아님"
