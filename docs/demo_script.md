## 제작 방법

- 화면은 로컬 실행(`uv run legaldoctor web`, 127.0.0.1)을 자동 조작해 녹화함. 상단 메뉴는 개념 이름(준비 중)으로 보임. 운영 서버 주소는 대회 영상에 쓰지 않음
- 녹화할 때 답변 캐시를 끔(`LD_ANSWER_CACHE=0`). 그래야 "실제 소요" 자막이 실제 값으로 나옴
- 투자계약 검진은 실행마다 개인 책임 조항 판정이 "보호 규정 있음/못 찾음"으로 갈릴 수 있음. 두 판정이 함께 나온 실행만 씀
- 규제팡은 가상 사업소개서(26번 사인 예시)만 올리고 항목을 고치지 않음. 자료를 더하거나 사업 카드를 고치면 미리 분석한 결과 대신 실제 분석(2~4분)이 돎
- 재검진에 붙여 넣는 조항에는 "이해관계인"이라는 말이 없어야 "낮음"으로 나옴(그 말이 남으면 같은 범주로 다시 잡힘)
- 화면이 음성보다 긴 장면(케어, 규제팡)은 최대 1.5배로 당김
- 터미널 장면에서 `.env`를 열지 않음. 키와 OC 값이 화면에 나오지 않게 함
