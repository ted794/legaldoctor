# 2단계 설계: 실행 관리(컨설팅)

- 작성 2026.11.17. 상태: 설계안(구현 전)
- 한 줄: 1단계가 진단서와 처방전이라면 2단계는 치료 계획, 경과 관찰, 재검진임

## 1. 왜 필요한가

- 지금 리걸닥터는 검진결과표와 "변호사 권장조치"를 주고 끝남. 창업자가 조치를 실제로 했는지, 고친 계약서가 맞는지, 그 사이 법이나 회사 상황이 바뀌었는지는 따라가지 않음
- 현장에서 사고는 대개 진단 뒤에 남. 권장조치를 미루거나 절반만 고치고, 투자·채용·신사업으로 회사가 바뀌면서 새 사인이 생김
- 2단계는 진단을 출발점으로 삼아 실행 과제를 관리하고, 바뀐 것을 다시 검진하고, 변화가 생기면 먼저 알려 주는 단계임

## 2. 단계 구분

| 구분 | 1단계 검진·처방(지금) | 2단계 실행 관리(신규) |
|---|---|---|
| 질문 | 무엇 때문에 죽을 수 있나 | 처방을 어떻게 실행하고 잘되고 있나 |
| 결과물 | 검진결과표, 변호사 권장조치, 규제 지도 | 실행 계획, 실행 보드, 재검진 전후 비교, 경과 보고서 |
| 시간 | 한 번 | 몇 주~몇 달 이어짐 |
| 저장 | 저장 안 함(노네임 모드) | 이어 보기 위한 저장이 필요함(4장) |

## 3. 이용 흐름

1. **실행 계획 만들기**
   - 검진결과표 끝에 "실행 계획 만들기" 버튼
   - 위험 항목마다 변호사 권장조치를 실행 과제로 나눔(Liner Model)
   - 과제마다: 할 일, 완료 기준, 필요한 자료, 관련 조문(원문 링크), 권장 기한, 누가 할 일인지(창업자 직접 / 전문가 확인 필요)
   - 예: "회생 시 즉시 상환 조항" → ① 투자자와 조항 삭제 또는 개인 책임 제외 협의 ② 수정 계약서 초안 받기 ③ 수정본 재검진 ④ 서명 전 전문가 확인
2. **실행 보드**
   - 할 일 / 진행 중 / 완료 / 보류 네 칸
   - 위쪽에 사인별 위험 게이지: 처음 검진 때와 지금을 나란히 보임
   - 기한이 지난 과제와 '전문가 확인 필요' 과제를 따로 표시
3. **실행 상담**
   - 과제를 열고 "투자자에게 뭐라고 말하나요?" "이렇게 고치면 되나요?"처럼 물음
   - 답은 검진결과표, 법령 원문, 사인 교훈을 근거로만 함. 근거 구절을 못 찾으면 답하지 않고 '전문가 확인 필요'로 넘김(1단계와 같은 원문 대조 원칙)
   - 협상 문구 초안, 체크리스트, 준비 서류 목록처럼 실행을 돕는 자료를 만들어 줌
4. **고친 자료로 재검진**
   - 수정한 계약서나 취업규칙, 처리방침을 올리면 해당 항목만 다시 검진
   - 전후 비교: "위험 높음 → 낮음", 남은 위험과 이유
   - 재검진에서 '낮음'이 나오면 과제를 완료로 옮길 수 있음
5. **변화 감지**
   - 법령 변화: 과제에 걸린 조문이 개정되면 알림(법제처 개정 이력)
   - 규제·판례 변화: 관련 사인의 최신 동향에 새 판례·처분이 나오면 알림(Liner Search)
   - 회사 변화: 정기 체크인 질문(투자 유치, 인원 증가, 신사업, 주요 거래처 변경)에 답하면 새로 생길 수 있는 사인을 짚어 재검진을 권함
6. **경과 보고서**
   - 처음 진단 대비 개선 현황을 한 장으로: 완료 과제, 줄어든 위험, 남은 과제, 다음 점검일
   - 이사회·투자자 보고나 변호사 상담 준비에 씀. 인쇄·PDF·DOC

## 4. 저장 방식(노네임 모드와의 관계)

2단계는 몇 주씩 이어지므로 어딘가에 기록이 남아야 함. 대회까지는 가입 없이 쓰는 원칙을 지킴.

| 안 | 방식 | 장점 | 단점 |
|---|---|---|---|
| A. 비밀 링크 | 가입 없이 무작위 주소로 실행 계획을 서버에 저장. 보관 기간을 정하고(예: 90일) 언제든 지움 | 다른 기기에서도 이어 봄. 변화 감지 알림을 화면에서 보여 줄 수 있음 | 링크를 잃으면 찾을 수 없음. 서버에 자료가 남아 처방침 개정 필요 |
| B. 파일 보관 | 실행 계획을 파일로 내려받고 다음에 다시 올림. 서버에는 저장 안 함 | 서버 보관 0. 공용 PC에서도 안전 | 이어 보기가 번거로움. 변화 감지는 파일을 올렸을 때만 |
| C. 회원 가입 | 로그인 계정에 저장, 이메일 알림 | 알림·정기 체크인까지 완성 | 노네임 모드와 충돌. 대회 뒤 회원 체계와 함께 설계 |

- 추천: 대회 전에는 **A(보관 90일, 지우기 버튼) + B(내보내기·불러오기)**를 함께 둠. 이메일 알림이 필요한 C는 대회 뒤 로그인 도입 때 붙임
- 비밀 링크는 "이 주소를 아는 사람은 누구나 볼 수 있음"을 크게 안내하고, 공용 PC에서는 B를 권함
- 보관 자료는 실행 계획, 과제 상태, 재검진 결과로 한정함. 올린 원본 파일은 1단계처럼 저장하지 않음

## 5. 법적 경계

- 리걸닥터는 무료로 일반 정보와 실행 도구를 주는 서비스로 남음. 특정 사건을 맡아 판단하거나 대리하지 않음(변호사법상 비변호사 법률사무 취급 문제를 피함)
- 실행 상담은 근거 조문과 일반적 권장조치 범위에서 답함. 계약 서명, 분쟁 대응, 신고·소송 같은 구체적 결정은 '전문가 확인 필요'로 표시하고 결과표와 경과 보고서를 들고 가게 함
- 특정 변호사로 연결하거나 소개하지 않음. 전문가는 이용자가 고름(전문가 협업 네트워크 원칙과 같음)
- 기록이 쌓이면 영업비밀과 개인정보가 늘어남. 보관 기간, 지우기, 접근 범위(비밀 링크)를 개인정보 처리방침과 이용약관에 반영함

## 6. Liner API 활용

| 기능 | Liner Model | Liner Search |
|---|---|---|
| 실행 계획 | 권장조치를 실행 과제로 나눔, 완료 기준·필요 자료 정리 | 같은 조치를 한 실제 사례(표준계약서, 정부 가이드) |
| 실행 상담 | 근거 기반 답변, 협상 문구·체크리스트 초안 | 최신 실무 자료와 정부 해석 |
| 재검진 | 수정본 조항 추출과 조문 판정(1단계 엔진) | 2차 보강(실제 판례·처분) |
| 변화 감지 | 체크인 답변으로 새 사인 판단 | 사인별 최신 동향 비교 |

## 7. 화면 배치

- 검진결과표 아래: "실행 계획 만들기" 큰 버튼
- 첫 화면 상단 메뉴 또는 '무엇을 도와드릴까요?' 옆: "내 실행 계획 이어 보기"(비밀 링크 붙여 넣기 또는 파일 올리기)
- 실행 보드 화면: 왼쪽 사인별 위험 게이지, 가운데 과제 보드, 오른쪽 선택한 과제의 상담 창

## 8. 만드는 순서

| 단계 | 범위 | 예상 |
|---|---|---|
| MVP(대회 전) | 실행 계획 만들기, 실행 보드, 항목 재검진 전후 비교, 경과 보고서, 저장 A+B | 1~2일 |
| 2차 | 실행 상담(근거 기반 대화), 법령 개정·최신 동향 변화 표시 | 2~3일 |
| 대회 뒤 | 로그인·이메일 알림, 정기 체크인, 전문가 협업 네트워크와 자료 공유 | 회원 체계와 함께 |

## 9. 성과 지표

- 과제 완료율, 재검진으로 줄어든 위험 높음 항목 수
- 재검진 횟수, 경과 보고서 생성 수
- '전문가 확인 필요' 비율(너무 높으면 상담 범위가 좁고, 너무 낮으면 경계를 넘는 신호)

## 10. 정할 것

1. 저장 방식: A+B로 갈지
2. 대회 전 범위: MVP까지만 할지, 실행 상담까지 할지
3. 이름: "실행 관리", "리걸닥터 케어", "경과 관찰" 가운데 무엇으로 부를지
4. 데모 영상에 2단계를 넣을지(넣으면 확장성 구간을 줄여야 함)
