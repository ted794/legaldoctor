# 규제팡 결선 발표자료 골자 (12.5, 발표 10분 + 질의 5분)

- 용도: 결선 발표 슬라이드 초안. 슬라이드마다 핵심 메시지 한 줄과 들어갈 내용
- 수치 [수치]는 평가를 끝까지 돌린 뒤 `out/eval/report.md`에서 채움
- 법인 명칭·로고는 쓰지 않음(대회 규정). 소속은 "국내 대형로펌"으로만 표기

## 1. 표지
- 규제팡 · 막힌 규제, 팡! 뚫어 드려요
- 법알못 창업자를 위한 규제 사전상담 에이전트

## 2. 문제: 숨은 규제와 선례 없는 신속확인
- 메시지: 창업자는 무엇을 물어야 할지 몰라 신속확인 문 앞에서 멈춤
- 규제는 시행령·시행규칙·고시·별표, 그리고 정부의 부정적 해석에 숨어 있음
- 공개 샌드박스 사례 2,859건 중 신속확인 개별 사례 공개는 0건
- 변호사 첫 답까지 보통 1주, 규제 검토 자문 비용은 공공 지원 기준 건당 100만 원 × 2~3건, 중대형 로펌 시장가 1,000만 원 안팎. 상담 시간의 70%가 사실관계 파악과 기초 조사

## 3. 해결: 규제팡
- 메시지: 변호사를 찾기 전 무료로 문제 소지를 먼저 알려 줌
- 입력 4종(스무고개·글·사업소개서·그림) → 판단 6단계 → 결과물 3종(규제 지도·신속확인 신청서 초안·상담 준비서)

## 4. 시연 (약 3분)
- 데모 영상 대본(`docs/demo_script.md`)의 시연 구간을 실시간 또는 녹화로

## 5. 범용 AI와 무엇이 다른가
- 메시지: 범용 AI는 그럴듯한 답을 주고 규제팡은 원문으로 확인한 근거와 확인하지 못한 공백을 나눠 줌
- 기획서의 비교 표(조문 근거, 숨은 규제, 선례, 그림자 규제, 사실 확인, 모르는 것, 결과)

## 6. 평가
- 메시지: 공개 승인 사례 10건 정답 대조에서 허위 조문 0건
- 규제팡 vs 범용 프롬프트: 법령 적중 [수치] / 조문 적중 [수치] / 허위 조문 [수치] / 트랙·창구 일치 [수치]

## 7. Liner API 활용
- 메시지: Liner Model과 Search는 후보를 내고 원문이 확정함
- Model: 그림·문서 이해, 스무고개 질문, 조문 적용 판정(근거 구절 필수)
- Search: 행위별 규제 단서, 정부 해석·보도해명 단서

## 8. 출구: 전문 변호사 상담으로 바로 연결
- 메시지: 규제팡은 상담을 대신하지 않고 상담을 빠르고 싸게 만듦
- 상담 준비서 한 장을 들고 가면 사실관계 파악과 기초 조사(상담 시간의 70%)를 건너뜀
- 신속확인으로 풀릴 문제는 신청서 초안으로 바로 정부에 물음
- 확인 필요: 특정 변호사로 연결하는 구조는 변호사법상 알선 금지(제34조)와 변협 광고 규정에 걸리지 않게 설계해야 함(무상 연결, 이용자 선택, 대가 없음)

## 9. 만든 사람
- 메시지: 샌드박스 심사위원석에 앉아 본 규제 전문 변호사가 자기 판단 순서를 에이전트로 옮김
- 국내 대형로펌 파트너 변호사, AI·플랫폼·테크놀로지 그룹 총괄
- 변호사·변리사·세무사. 대한변호사협회 지정 IT 전문변호사·지식재산권 전문변호사
- 서울중앙지검 첨단범죄수사부 검사 출신, 2012년 테크·규제혁신 전문 법률사무소 창립
- 규제샌드박스 심의: 산업통상자원부 산업융합 규제샌드박스 심의위원회, 과학기술정보통신부 ICT 규제샌드박스 사전심의, 중소벤처기업부 규제샌드박스 심의위원회 위원
- 규제혁신 공직: 국무총리실 신산업규제혁신위원회 위원, 대통령 소속 4차산업혁명위원회 사회제도혁신위원(1기), 디지털플랫폼정부위원회 위원(2022–2025), 개인정보보호위원회 위원(2014–2017)
- 스타트업 정책: 코리아스타트업포럼 부의장, 대한변협 스타트업규제혁신특별위원회 부위원장. 10여 년간 스타트업 규제정책에 참여
- 대통령 표창(창업벤처진흥유공, 2021), 저서 『미래는 규제할 수 없다』(2018)

## 10. 확장성과 임팩트
- 사례 DB 자동 갱신, 특례 뒤에도 남은 규제를 모은 규제 개선 과제 목록
- 창업 지원기관·액셀러레이터 배포, MCP로 다른 AI 도구에서 호출(구현 시)
- 마무리: 막힌 규제, 팡!

## 질의 대비
- 원문을 못 읽으면? 공백으로 단정하지 않고 "원문 확인 불가"로 보류하고 멈춤
- 특례 뒤 법령이 바뀌었으면? 개정 이력만 알리고 규제 해소는 단정하지 않음
- 법률 자문 아닌가? 모든 결과물에 상담 준비 자료로 표시, 최종 판단은 부처·변호사
- 데이터 출처와 개인정보? 공개 자료만 사용, 사례 DB에 개인 이름·연락처 없음
