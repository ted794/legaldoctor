# 스타트업 리걸닥터 결선 발표자료 골자 (12.5, 발표 10분 + 질의 5분)

- 용도: 결선 발표 슬라이드 초안. 슬라이드마다 핵심 메시지 한 줄, 들어갈 내용, 시간 배분
- 이름: 서비스는 스타트업 리걸닥터(Startup Legal Doctor). 규제가 사업을 막는 외인성 사인을 맡는 메뉴가 규제팡(막힌 규제, 팡! 뚫어 드려요), 운영 단계 메뉴가 계약·노무 검진
- 포지셔닝: 창업 단계의 BM 적법성 검토와 규제샌드박스 신청이 1단계(구현). 같은 엔진으로 운영 단계(투자계약·노무) 검진까지 시연하고, 스타트업이 죽는 28가지 사인 전체로 넓힘. 위험이 높은 항목은 변호사 심화자문으로 연결
- 평가 수치는 2026.11.14. 실행 결과(`out/eval/report.md`). 제출 전에 한 번 더 돌려 최종값으로 바꿈
- 법인 명칭·로고는 쓰지 않음(대회 규정). 소속은 "국내 대형로펌"으로만 표기

## 1. 표지 (0:00–0:15)
- 스타트업 리걸닥터 · Startup Legal Doctor
- 스타트업이 죽는 28가지 사인을 죽기 전에 검진함
- 메뉴: 규제팡(막힌 규제, 팡! 뚫어 드려요) · 계약·노무 검진

## 2. 문제: 스타트업은 규제와 계약에서 죽음 (0:15–1:15)
- 메시지: 창업할 때는 숨은 규제가, 운영할 때는 계약과 노무가 회사를 죽임. 창업자는 무엇을 물어야 할지 모름
- 창업 단계: 규제는 시행령·시행규칙·고시·별표와 정부의 부정적 해석에 숨어 있음
- 신속확인 제도가 있지만 공개 샌드박스 사례 2,859건 중 신속확인 개별 사례 공개는 0건. 참고할 선례가 없음
- 운영 단계: 투자계약의 "회사 및/또는 이해관계인" 한 줄로 창업자 개인이 상환 책임을 지고, 프리랜서로 쓴 개발자가 근로자로 판단되면 체불·소급 부과가 한꺼번에 옴
- 비용과 시간: 변호사 첫 답까지 보통 1주. 규제 검토 자문은 공공 지원 기준 건당 100만 원, 충분한 검토에 2~3건(200~300만 원), 중대형 로펌 시장가 1,000만 원 안팎. 상담 시간의 70%가 사실관계 파악과 기초 조사

## 3. 해결: 어디서든 들어와 같은 엔진으로 (1:15–2:00)
- 메시지: 후보는 AI가 내고, 확정은 원문이 함
- 그림: `docs/figures/difference.png`(16:9, 3840×2160), 원본 `docs/figures/difference.svg`
- 입구: 창업 단계(BM 적법성·샌드박스), 운영 단계(투자계약·노무). 입력은 스무고개·글·문서·그림
- 엔진: 사실 확인 → 후보 생성(Liner) → 원문 대조 관문 → 숨은 규제·선례·그림자 규제
- 출구: 규제 지도·검진표, 신속확인 신청서 초안, 변호사 심화자문

## 4. 시연 1: 규제팡 메뉴, 창업 단계 (2:00–3:30)
- 가상 사례: 아파트 단지 안 자율주행 로봇 편의점 배달
- 그림으로 흐름을 그리고 스무고개 두 문항 → BM 확인 → 규제 지도(명시·의제·해석·공백, 위임 경로, 현존 규제 표시) → 신속확인 신청서 초안·상담 준비서
- 대본: `docs/demo_script.md` 시연 구간

## 5. 시연 2: 계약·노무 검진 메뉴, 운영 단계 (3:30–4:40)
- 메시지: 같은 엔진이 계약서를 읽고 창업자를 죽일 조항을 짚음
- 투자계약 검진(13장): 가상 신주인수계약을 올림 → "투자대상기업 및/또는 이해관계인" 상환 조항, 위약벌 2배, 회생 시 즉시 상환을 원문 그대로 짚음 → 창업자를 지켜 줄 규정을 찾지 못한 조항은 "보호 공백"으로 위험 높음 → 변호사 심화자문 권함
- 노무 검진(21장): 출근하는 프리랜서, 포괄임금, 스톡옵션 구두 약속, 급여 일부 미지급 → 근로기준법 원문 대조 → 지금 할 일
- 검진표 한 장: 막을 사인의 진단 사슬, 항목별 위험·원문·법령 대조·지금 할 일
- 웹 화면 "계약·노무 검진" 메뉴에서 "가상 예시 불러오기"로 바로 시연

## 6. 평가 (4:40–5:40)
- 메시지: 공개 승인 사례 10건에서 범용 AI보다 핵심 법령을 더 찾고, 찾은 조문은 모두 원문으로 확인함
- 방법: 입력에서 법령명·특례 결과를 지우고, 같은 사례와 그 뒤의 사례는 선례 검색에서 뺌. 비교 대상은 같은 Liner Model에 범용 프롬프트로 물은 결과

| 항목 | 리걸닥터 | 범용 프롬프트 |
|---|---:|---:|
| 핵심 법령 적중(시행령·시행규칙 포함) | 80% | 70% |
| 핵심 법령 적중(정확한 법령명) | 75% | 50% |
| 조문 적중 | 45% | 33% |
| 허위 조문 | 0 | 0 |
| 트랙 일치 | 8/10 | 8/10 |
| 창구 일치 | 5/10 | 8/10 |
| 평균 소요 | 174초 | 6초 |

- 보여 줄 사례: 병원 의무기록 모바일 조회. 범용 쪽은 의료법·개인정보 보호법만 냈고 리걸닥터는 정답인 정보통신망법(연계정보 이용)까지 찾음
- 정직하게 말할 것: 허위 조문은 이번 실행에서 양쪽 모두 0건(첫 실행에서 범용 쪽 1건). 리걸닥터의 차이는 "0건이 구조적으로 보장된다"는 점. 창구 판정과 속도는 범용 쪽이 앞섬. 3분은 변호사 첫 답 1주와 비교함

## 7. Liner API 활용 (5:40–6:20)
- 메시지: Liner Model과 Search는 후보를 내고 원문이 확정함
- Model: 그림·문서 이해, 스무고개 질문, 계약 조항 추출, 조문 적용 판정(근거 구절 필수)
- Search: 행위·조항별 규제 단서, 정부 해석·보도해명 단서
- 원문 대조로 막은 허위 조문 예시 한 건(평가 첫 실행에서 교통약자 병원 동행 사례 4건 탈락)

## 8. 출구: 변호사 심화자문으로 바로 연결 (6:20–7:00)

- 스타트업 리걸닥터. 막힌 규제는 팡!

## 질의 대비
- 원문을 못 읽으면? 공백으로 단정하지 않고 "원문 확인 불가"로 보류하고 멈춤
- 특례 뒤 법령이 바뀌었으면? 개정 이력만 알리고 규제 해소는 단정하지 않음
- 범용 AI도 법령을 꽤 맞히는데? 맞힌 것과 확인한 것은 다름. 리걸닥터는 원문 근거 구절로 확인하고 숨은 단계(시행규칙·고시·별표)와 현존 여부까지 봄
- 왜 느린가? 조문마다 원문을 받아 대조하기 때문. 변호사 첫 답 1주와 비교하면 3분임
- 왜 투자계약·노무부터? 부검보고서에서 창업자 개인을 직접 죽이는 사인(13장 개인 상환책임, 21장 체불 형사책임)이고 회생해도 따로 가는 책임이라 가장 치명적임
- 법률 자문 아닌가? 모든 결과물에 상담 준비 자료로 표시, 최종 판단은 부처·변호사
- 변호사 연결이 알선 아닌가? 무상 연결, 이용자 선택, 대가 없음으로 설계함
- 데이터 출처와 개인정보? 공개 자료만 사용, 사례 DB에 개인 이름·연락처 없음, 업로드 자료는 저장하지 않음
- 기존 저작물? 사인 분류 체계는 참가자의 기존 집필물이며 README에 표시함. 코드와 데이터는 대회 기간에 새로 만듦
