시행일 2026년 11월 14일 · 리걸닥터로 돌아가기

리걸닥터는 회원 가입 없이 쓰는 무료 사전상담 서비스입니다. 이용자가 올린 자료는 분석하는 동안에만 쓰고 저장하지 않습니다. 사업 분석을 위해 입력 내용이 AI 모델 서비스(라이너)로 전송됩니다. 다른 사람의 개인정보, 주민등록번호 같은 고유식별정보, 건강 정보 같은 민감정보, 공개하면 안 되는 영업비밀은 빼고 입력해 주세요.

1. 처리하는 정보

구분항목목적
이용자가 입력한 자료사업 설명 글, 스무고개 답변, 사업소개서·계약서 등 업로드 파일, 그림·사진사업 모델 파악, 규제·계약·노무 검진, 결과물 작성
자동으로 생기는 정보접속 IP 주소, 접속 일시, 요청 경로과도한 이용 차단(남용 방지), 장애 대응

회원 가입, 이름, 연락처, 결제 정보는 받지 않습니다. 쿠키로 이용자를 추적하지 않습니다.

2. 보관 기간과 파기

  • 입력 자료와 결과물(규제 지도, 상담 준비서, 신청서 초안, 검진표)은 서버 메모리에만 두고 파일이나 데이터베이스에 저장하지 않습니다. 이용자가 화면을 닫거나 서버가 다시 시작되면 사라집니다.
  • 남용 방지를 위한 IP 주소별 이용 횟수는 메모리에 최대 24시간 둔 뒤 지웁니다.
  • 웹서버 접속 기록은 서버 보안을 위해 웹서버 설정에 따라 일정 기간 보관한 뒤 지웁니다.
  • 분석 중 조회한 법령 원문은 다시 쓰기 위해 저장합니다. 법령 원문은 공개 자료이며 이용자 정보가 들어 있지 않습니다.

3. 외부 서비스로 전송

받는 곳보내는 내용목적
라이너(Liner Platform API)입력 자료에서 읽은 사업 설명, 계약 조항, 질문 문장, 그림AI 모델로 사업 분해, 후보 법령 생성, 조문 적용 판정, 검색
국가법령정보센터(법제처)법령 이름, 조문 번호, 검색어법령 원문 조회

라이너가 받은 정보를 처리·보관하는 방식은 라이너의 이용약관과 개인정보 처리방침을 따릅니다. 리걸닥터는 이용자 정보를 판매하거나 광고에 쓰지 않습니다.

4. 이용자의 선택

  • 필요한 만큼만 입력하면 됩니다. 회사 이름이나 사람 이름을 지우거나 바꿔 넣어도 분석할 수 있습니다.
  • 입력을 그만두려면 화면을 닫으면 됩니다. 저장된 자료가 없으므로 따로 삭제를 요청할 필요가 없습니다.

5. 결과물의 성격

리걸닥터의 결과물은 법률 자문이 아니며 변호사 상담과 규제샌드박스 신청을 준비하는 참고 자료입니다.
